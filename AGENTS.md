# Project instructions

Before creating or changing any user-facing interface, visual asset, or styling in this project, read and follow [the Hotevo visual system skill](.agents/skills/hotevo-apple-marketing/SKILL.md). Treat it as the project-wide design source of truth so additions remain visually consistent with existing work.

Apply the skill to new UI and relevant touched components. Avoid unrelated visual rewrites when fixing a narrow issue. A clear, specific user request that changes the design takes precedence for that requested change; keep the rest of the interface aligned with the skill.
